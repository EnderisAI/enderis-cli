# Enderis CLI

Release downloads for the `enderis` CLI. The source lives elsewhere; this repository only holds releases.

Install on macOS or Linux:

```sh
curl -fsSL https://enderis.ai/install.sh | sh
```

The CLI keeps itself up to date. Each release ships a minisign-signed `latest.json`; the CLI verifies it before installing an update.

Documentation: https://enderis.ai/docs/cli/reference
